# Project Instructions

## Environment

This is a Python 3.12 project.

use the virtual environment:

source /home/ubuntu/projects/experiments/verl/bin/activate

## GOAL

create multi agent setup under this folder ./verl/experiment/multiagent

1. current PPOTrainer under verl/trainer/ppo/v1/trainer_base.py only handles one actor in the system. You need to elevate this system to multiple actors in the system

2. Below are the specificiations for the actors.
1) Those actors could start with each other or with an environment. 
2) Each actor usually receives a different system prompt to serve with a different role. 
3) Actor interact with each other through a message system which can be similar to a tool call. Also implement this message passing system through shared storage system such as transfer queue.
4) Actors can be instantiated with the same model (main) or different model (weaker or stronger). When it's main/stronger model interaction, the stronger model may serve as oracle. When it's main/weaker model interaction, main model could serve as a teacher to learn how to each a weaker model to execute. 

3. trajectory from each individual actors can still be saved to transfer queue with a actor_id to label each actor. When the actors share the same model and the trajectories are on-policy, gradients can be generated by simply reading from trajectories stored in transfer queue. But be sure to optimize this since agents may or may not share the same prefixes. 

4. The purpose of this setup is to convert Standard RL to multiagent multiturn RL, even for standard RL datasets, such as GSK8k or MATH500. 

5. Also provide a mechanism to create diverging but cooperative system prompts for each actors so that those actors can cooperate with each other.
